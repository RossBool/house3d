# 批注同步到飞书多维表格 · 接入步骤

架构：

```
[网页批注]  --POST /note-->  [Cloudflare Worker]  --Bearer-->  [飞书多维表格]
[网页面板]  <--GET /notes--  （唯一持有 app_secret）
```

前端零密钥，任何人打开网页都能批注；表格由飞书原生实时汇总，网页端每 10 秒拉取一次，能看到所有人的意见。

---

## 一、建飞书自建应用（拿 app_id / app_secret）

1. 打开 [飞书开放平台](https://open.feishu.cn/app) → 创建企业自建应用（名称随意，如"住宅楼模型批注"）。
2. **凭证与基础信息** 页复制 `App ID`、`App Secret`（后面填到 Worker 环境变量）。
3. **权限管理** 开通：
   - `bitable:app`（查看、评论、编辑和管理多维表格）
   - `drive:drive`（上传素材，缩略图附件需要）
4. **版本管理与发布** → 创建版本并发布（企业内自建应用通常需管理员审批）。

## 二、建多维表格（拿 app_token / table_id）

1. 新建一个多维表格，URL 形如：
   `https://xxx.feishu.cn/base/`**`bascnXXXX`**`?table=`**`tblXXXX`**
   - `/base/` 后面那段 = `BITABLE_APP_TOKEN`
   - `?table=` 后面那段 = `TABLE_ID`
2. **数据表不用手工建字段**——部署好 Worker 后访问一次 `/health`，它会按下面的表自动补齐缺失字段（含单选选项）。

| 字段名 | 类型 | 说明 |
|---|---|---|
| 批注ID | 文本 | 幂等键，网页生成 |
| 楼层 | 文本 | 如"七层平面图" |
| 对象 | 文本 | 如"双人床" |
| 类型 | 文本 | 家具 / 房间 / 墙体 |
| 类别 | 单选 | 位置 / 朝向 / 尺寸 / 材质 / 增删 / 其他 |
| 意见 | 多行文本 | 批注正文 |
| 坐标 | 文本 | 如 "x5.35 y-0.14" |
| 视角 | 文本 | 相机位姿，可复原视角 |
| 署名 | 文本 | 批注人 |
| 状态 | 单选 | 待处理 / 已改 / 驳回 |
| 缩略图 | 附件 | 批注时的画面截图 |
| 时间 | 日期 | 精确到分 |

3. 点表格右上角 **⋯ → 更多 → 添加文档应用**，把第一步的自建应用加进来并给 **可编辑** 权限（否则报 1254302 Permission denied）。

## 三、部署 Worker 代理

```bash
cd house3d/worker
npx wrangler deploy feishu-proxy.js --name house3d-note-proxy
```

部署后在 Cloudflare 控制台给 Worker 配置环境变量（Settings → Variables and Secrets）：

| 变量 | 值 |
|---|---|
| FEISHU_APP_ID | 第一步的 App ID |
| FEISHU_APP_SECRET | 第一步的 App Secret |
| BITABLE_APP_TOKEN | 第二步的 app_token |
| TABLE_ID | 第二步的 table_id |
| ALLOW_ORIGIN | `https://rossbool.github.io` |

自检：

```bash
curl https://<你的worker>.workers.dev/health
# → {"ok":true,"table":"configured"}
```

## 四、接到网页

两种方式任选：

- **临时联调**：打开网页时带参数
  `https://rossbool.github.io/house3d/?sync=https://<你的worker>.workers.dev`
- **永久启用**：编辑 `app.js` 里批注模块顶部的配置，把 URL 填进 `SYNC.url` 后重新发布：

```js
const SYNC = { url: 'https://<你的worker>.workers.dev', pollMs: 10000 };
```

启用后批注面板右上角会显示 **"云端已连接"**，卡片上：
- 自己的批注：`… 待同步` → `✓ 已同步`
- 别人的批注：`☁ 他人`（只读，可定位、可改状态、可复制）

## 五、日常使用与排错

- **实时性**：表格端是秒级（飞书原生）；网页端每 10 秒拉一次，切换批注模式时立即拉一次。
- **离线**：Worker 不可用时批注仍存本地，恢复后不会自动补传（可再次编辑保存触发），导出 JSON 不受影响。
- **常见错误**：
  - `1254045 FieldNameNotFound`：字段名与上表不一致。
  - `1254302 Permission denied`：应用没被加进这张表，或没给可编辑权限。
  - `1254291 Write conflict`：同一张表并发写入，重试即可。
  - 缩略图没进表格：检查 `drive:drive` 权限是否开通。

## 六、本地联调（不用真飞书）

```bash
node worker/mock-proxy.js        # 起在 8901，模拟代理
# 打开 http://localhost:8899/index.html?sync=http://localhost:8901
```

mock 会把收到的批注打印到终端，并预置一条"他人批注"用于验证合并显示。
